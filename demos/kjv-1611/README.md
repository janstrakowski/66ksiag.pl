# KJV UI — 1611 folio (WIP)

English UI for the King James Version will use a **different visual language** than the BG copperplate theme.

## Reference scans

- Original 1611 KJV folio (PDF / page images):  
  https://www.originalbibles.com/the-original-king-james-bible-1611-pdf/

Inspiration targets: black-letter / roman title pages, dense double-column scripture, running titles, ornamental initials — **not** a copy of the Gdańsk miedzioryt plate.

## Status

- Text API: `/kjv/1769/…` (public-domain KJV text; same book IDs and chapter counts as BG).
- App: English strings + light `theme-kjv` placeholder until demos land here (same flow as `demos/versions/` for BG).

## Numbering

All editions in this project share **KJV/Protestant chapter–verse numbering**. BG 1879 is remapped to that grid so one daily plan works across languages.
